ONE REPOSITORY. YOUR RULES.

Runs quietly in the background.

Watchtower lives in its own GitHub repository. It observes your projects without adding files to them or changing a single dependency.

  1. 01

    Fork the template

    Start with a ready-to-run GitHub Actions workflow and an empty project list.

  2. 02

    Add your repositories

    Paste the GitHub URLs you want to monitor. Private repositories use a read-only GitHub secret.

  3. 03

    Get the signal

    A daily scan records history, updates your dashboard, and can send a short Telegram report.

ZERO HOSTING BILL

Powered by the GitHub account you already use.

GitHub Actions runs the scheduled scan on a temporary runner. The result is saved in your Watchtower repository. There is no Watchtower server, no database to operate, and no subscription.

for the Watchtower software and its hosting architecture
